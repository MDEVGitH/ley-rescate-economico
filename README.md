# ley-rescate-economico

**Leyes Transparentes**: calculadora que compara cuánto le llega al mes a un empleado hoy y con el Proyecto de Ley 477 de 2026 Cámara (Ley de Rescate Económico).

- `html/index.html`: página principal
- `css/styles.css`: estilos (tema oscuro, responsive)
- `javascript/app.js`: cálculo de retención en la fuente y gráficos
- `multimedia/`: PDF del proyecto de ley y QR de donaciones
- `vercel.json`: configuración para publicar en Vercel

Herramienta informativa, no constituye asesoría tributaria.
